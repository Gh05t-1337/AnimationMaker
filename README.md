# Animation Maker

A tiny, offline Android app for making videos out of image sequences: pick photos,
put them in order, set a speed, export an MP4.

# How this was coded

This app was one-shot vibe coded by the free version of claude with the following prompt:
```
code a stop motion app. i will publish it on fdroid, so it should be small and simple and dont have any unnecessary dependencies. it should basically only have the following set of features:

* select images from gallery
* control where which image should be in the sequence (if multiple images are selected from the gallery at once, they should have the order they were selected in, but it should be possible to change order)
* control speed (fps)
* export as video
```

here's a link to the chat: https://claude.ai/share/dfd2a4cf-c120-4b86-8846-30b101ca5525

# Why this was coded

I tried making a simple small stop motion video, so i made some images and then realized that i couldn't find any app on fdroid that allowed to combine them into a video.

This one-shot vibe coded tool allows you to convert image sequences into a video. it doesn't have any other features and i currently don't plan on implementing more features. hope it is still helpful to someone.
